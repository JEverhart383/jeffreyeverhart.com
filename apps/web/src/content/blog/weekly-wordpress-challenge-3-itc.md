Good Morning ITCs, I hope everyone had a nice, abbreviated week because of fall break. Wordpress Challenge 3: Add widgets to your Wordpress page and then write a post about which widgets you selected and why. You can add widgets in the dashboard by going to Appearance>Widgets. Each theme will have different options for how many widgets it will let you install, so each of you will have a different number of widgets to choose from. Let me know if you have questions. Have a good week and keep up the hard work. -Jeff
