The ground-floor session: what "headless" actually means next to a traditional
CMS, and then the specifics of doing it with WordPress. Four questions carry the
hour — how the two architectures differ, which APIs you can talk to WordPress
with, whether you can model custom or complex data in it, and what the front end
and hosting look like once the CMS stops rendering pages.

One thing has since gone stale: the content-modeling section uses Atlas Content
Modeler, which is no longer the recommendation. Use
[Advanced Custom Fields](https://www.advancedcustomfields.com/) instead. The
modeling concepts hold; only the plugin changed.
