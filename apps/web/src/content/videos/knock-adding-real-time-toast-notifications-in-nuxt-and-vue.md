For most developers toasts aren’t a new concept, but Knock’s real-time feed API
allows you to bind toast notifications in your frontend application to events
that are happening outside a user’s session: maybe a user posts a comment, or
some other scheduled event happens.

In this video, we’ll look at how we can implement real-time toasts using Nuxt,
shadcn/ui, and Knock. This video builds on a previous tutorial on creating an
in-app notification feed, so be sure to check that out.
