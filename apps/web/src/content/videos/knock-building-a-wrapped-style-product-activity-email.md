Wrapped-style emails turn user data into personalized stories, which is what
makes year-in-review campaigns like Spotify’s so popular.

Instead of talking about your product, you can transform data points into
meaningful narratives that drive engagement, retention, and emotional connection
with your brand.

In this video, we’ll explore how to build a ‘wrapped-style’ feature for a
collaboration app using Next.js, Tinybird, and Knock. We’ll cover the following
things:
- ingesting comment actions using Tinybird’s Events API
- transforming weekly comments into aggregate statistics using Tinybird’s Data
Pipes
- creating a scheduled workflow in Knock to query Tinybrid and send
timezone-aware emails using Postmark
