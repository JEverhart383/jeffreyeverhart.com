In this video, you'll learn how to create an in-app notification feed in an
Astro project using Knock. This tutorial covers setting up Knock workflows,
using Knock's React components, and triggering notifications from Astro API
routes. The demo app uses WorkOS & Authkit for authentication, Knock for
notifications, and React as a frontend framework. Let me know if you have any
questions in the comments!
