Today we’re expanding the capabilities of our commit system to include the
ability to revert a specific commit. Reverting a commit makes it easy to undo a
set of changes you already committed.

Previously when using the Knock commit system, there was no way to reverse a
change that had been committed. With revert commits, you can reverse a change
directly in the dashboard.
