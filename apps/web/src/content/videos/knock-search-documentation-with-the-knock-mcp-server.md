Providing AI tools like Cursor or Claude desktop the right context can help you
complete your tasks faster and more accurately. The Knock documentation provides
several ways to integrate context into your favorite LLM-based tools: llms.txt,
.md doc pages, and a RAG endpoint in the Knock MCP server.

Knock is infrastructure to send product and customer messaging across channels
like email, SMS, Slack, in-app, and more. In the next video in this series we'll
look at how to create cross-channel workflows.
