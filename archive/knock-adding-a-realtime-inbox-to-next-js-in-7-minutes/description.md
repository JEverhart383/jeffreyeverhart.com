# Adding a realtime inbox to Next.js in 7 minutes

Source: https://www.youtube.com/watch?v=h2yBzQCTU7s
Captured: 2026-09-13

---

If your product sends too many emails or SMS messages, users will start to tune you out. In-app messages in feeds or inboxes can provide value while a user is actually inside your product. 

Knock provides realtime infrastructure and components to create customized feeds and inboxes. Check out this speed run of Knock's Next.js quickstart guide to get started: https://docs.knock.app/getting-started/quick-start/nextjs
