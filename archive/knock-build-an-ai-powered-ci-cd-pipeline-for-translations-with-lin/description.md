# Build an AI-powered CI/CD pipeline for translations with Lingo.dev

Multilingual applications require translations across UI, marketing copy, and notifications in all messaging channels. AI-powered tools like Lingo.dev help streamline this process. 

This video will show you how to generate translations via the command line and integrate them into CI/CD pipelines. We'll use Knock's translation files as our example, but the approach works for any application surface requiring localization. Learn how to speed up your translation process while maintaining message consistency across channels.
