# Building an inbox to simplify support | Thena.ai and Knock

Source: https://www.youtube.com/watch?v=HlwE3zZceFQ
Captured: 2026-09-13

---

In this video, Jeff Everhart and Mike Molinet, founder of Thena, discuss Thena’s new inbox feature, which is powered by Knock’s in-app messaging primitives. Thena consolidates support tickets across different channels - like Slack, email, in-app chat, and even Microsoft Teams - to help support agents be more productive. Thena’s inbox feature addresses the challenges of high volume support by consolidating all interactions into a single interface. This streamlines the support workflow, reduces response time, and ultimately improves customer satisfaction.

Thena's inbox feature is built using Knock's real-time in-app infrastructure and SDKs.
