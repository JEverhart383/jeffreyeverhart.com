# Create notification workflows with Knock MCP Server | Email, SMS, push, in-app, Slack

With the Knock MCP server you can work with resources in your Knock account in AI tools like Cursor or Claude Desktop using natural language. This video covers how to get started use the Knock MCP server to create cross-channel notification workflows and messaging templates. 

Knock is infrastructure to send product and customer messaging across channels like email, SMS, Slack, in-app, and more. In the next video in this series we'll look at how to create cross-channel workflows.
