# Get started with the Knock MCP server | Email, SMS, push, in-app, Slack

Source: https://www.youtube.com/watch?v=6rIOkz9Kc20
Captured: 2026-09-13

---

We're excited to introduce the Knock MCP server which will let you work with resources in your Knock account in AI tools like Cursor or Claude Desktop using natural language. This video covers how to get started using the Knock MCP server and installing it in your favorite tools. 

Knock is infrastructure to send product and customer messaging across channels like email, SMS, Slack, in-app, and more. In the next video in this series we'll look at how to create cross-channel workflows.
