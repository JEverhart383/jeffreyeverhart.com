# Getting started with Knock Guides

Source: https://www.youtube.com/watch?v=lKYfB3FYMtk
Captured: 2026-09-13

---

If you're using a legacy in-app vendor and a script tag to show your users in-app messages, there's a better way. 

Knock Guides allow you to dynamically power in-app messages like banners, feature announcements, and upgrade nudges using your own components. This feature combines the sophisticated targeting logic that marketing and product teams need, with a developer-first approach that gives you full control over the behavior and design of your messaging. Now anyone can create and display messages in their product, without sacrificing performance or compromising on design like with legacy in-app vendors.

Check out the docs to get started: https://docs.knock.app/concepts/guides
Start building your own components: https://docs.knock.app/in-app-ui/guides/overview
