# Getting started with preferences in Knock

Source: https://www.youtube.com/watch?v=FCQGquTJlL0
Captured: 2026-09-13

---

User preferences are an important part of any notification system. They let users customize their product experience so that they only get alerts about things they care about on the channels that are important to them. Knock provides developers with a powerful preferences API that lets you model a user's preferences at a pretty granular level. 

In this video, we'll cover how to model a user's preferences in Knock, how to build a basic preference center component in React, and then we'll look at how Knock applies those preferences during workflow runs so that you can view and debug them in your logs.
