# Introducing SlackKit

Source: https://www.youtube.com/watch?v=xsw24iuUTLg
Captured: 2026-09-13

---

Slack powers collaboration for over 700,000 businesses, so if you’re looking for ways to provide value to your app’s users, a Slack integration is something worth considering. SlackKit is a collection of React components that use Knock resources to create a drop-in Slack integration for apps and products.

You can read more in the official docs and explore the example project demo'd here:
https://docs.knock.app/integrations/chat/slack-kit/overview
https://github.com/knocklabs/slack-kit-example
