# Introducing TeamsKit

Source: https://www.youtube.com/watch?v=rXbKCa4g0kg
Captured: 2026-09-13

---

In this interview Jeff Everhart and Matt Mikolay talk about Matt's experience building TeamsKit, a set of React components and APIs that allow developers to create product integrations with MS Teams without writing custom code. Here are a few of the topics they discuss:
- How the data models between Slack and MS Teams are different 
- How to navigate MS docs and products to create a Teams bot
- How TeamsKit simplifies creating a Teams integration
