# Marketplace notifications with Knock and Next.js

Source: https://www.youtube.com/watch?v=6h_mIWgjJFU
Captured: 2026-09-13

---

Learn how to build best-in-class marketplace notifications using Knock and Next.js. In this tutorial/demo, we'll add three essential notification patterns to a tour marketplace app: 
- coordinating buyer and seller communication through a single workflow
- managing inventory updates with an automated subscription system 
- and sending personalized weekly digest emails. 

Using Knock's workflow engine, you'll see how to handle complex scenarios like batching operator notifications, scheduling tour reminders, and automatically notifying subscribers when new inventory becomes available.
