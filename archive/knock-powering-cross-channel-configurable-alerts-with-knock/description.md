# Powering cross-channel configurable alerts with Knock

Source: https://www.youtube.com/watch?v=Pnj864esV-w
Captured: 2026-09-13

---

Alerts are an essential feature in many applications. They draw user attention to specific events or states within your product, keeping them informed and helping them take action if necessary. Effective alerting features provide users with choice over who receives alerts, which events trigger them, the delivery channels, and the timing of these alerts.

In this video, we will explore how to create a user-controlled alerting workflow in Knock. We'll look at:
- using alerts stored in your system to trigger workflows
- modeling alerts directly in Knock using objects and subscriptions
- leveraging a single workflow with dynamic logic

You can find the example app and additional instructions here: https://docs.knock.app/guides/alerting
