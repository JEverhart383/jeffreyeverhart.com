# Translations 2.0 demo

Source: https://www.youtube.com/watch?v=8VAFqj5qqPI
Captured: 2026-09-13

---

This video shows a quick demo of some of the new features we're brining to translations at Knock. You can now use a t tag in liquid to automatically generate a system translation file and then use the CLI/mAPI to fetch translations as PO files for better interoperability with automated translation services.

Learn more in the docs: 
https://docs.knock.app/concepts/translations
